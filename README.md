Smart Study Planner
A simple Python project that helps students organize their study tasks, prioritize them using basic AI logic, and stay motivated.
This project was built as part of a Bring Your Own Project (BYOP) capstone activity for the Digital Literacy course.

 Features
- Add tasks with deadlines and importance levels.
- AI‑like priority scoring: Combines urgency (deadline proximity) and importance to suggest which task to do first.
- Smart reminders for upcoming deadlines.
- Random motivational quotes to keep you focused.
- Beginner‑friendly code with clear comments.
How It Uses Basic AI
- Priority Calculation: Simple algorithm that scores tasks based on urgency + importance.
- Adaptive Scheduling: Tasks are automatically sorted by priority.
- Rule‑based Reminders: Flags urgent tasks and suggests focus areas.
- Randomized Motivation: Mimics human‑like encouragement.
This is not advanced machine learning — it’s basic AI logic designed to be easy to understand and extend.
Requirements
- Python 3.x
- No external libraries required (uses only built‑in modules like datetime and random).
Usage
- Clone the repository
- Run the program
