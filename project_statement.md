The Smart Study Planner is a beginner‑friendly Python project designed to help students organize their academic tasks more effectively. It was developed as part of a Bring Your Own Project (BYOP) capstone activity in the Digital Literacy course.
The project addresses a common student challenge: balancing multiple assignments, deadlines, and priorities. Traditional planners are static and often fail to adapt to changing schedules. This planner introduces basic AI logic to make study planning smarter, more adaptive, and more supportive.
Objectives
- Provide a simple tool for students to add, track, and prioritize tasks.
- Use AI‑like decision logic to calculate task priority based on urgency (deadline proximity) and importance.
- Generate adaptive study schedules that update dynamically as deadlines approach.
- Offer smart reminders for urgent tasks and motivational quotes to encourage productivity.
- Demonstrate how basic AI concepts (priority scoring, rule‑based reminders, simple NLP extensions) can be applied in real student tools.
Why This Matters
This project connects directly to digital literacy themes:
- Responsible use of digital tools for time management.
- Awareness of habits (urgency vs. procrastination).
- Practical application of AI in everyday student life.
It shows that even first‑year students can build meaningful projects that combine coding skills with problem‑solving and reflection.

Future Scope
- Add a chatbot interface for interactive commands.
- Integrate natural language input (e.g., “Finish math homework by Friday”).
- Save tasks persistently in a database or file.
- Build a simple GUI for easier use.

 This project is not just about coding — it’s about demonstrating digital responsibility, awareness, and creativity through a real‑world solution.
